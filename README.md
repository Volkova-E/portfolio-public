## 📂 Проекты

### 1. Предобработка и исследовательский анализ данных (EDA):
Проект включает полный цикл работы с микроданными Росстата: от очистки до сегментации целевой аудитории.
- Обработка пропусков, дублей и выбросов
- Преобразование и кодирование категориальных признаков
- Расчет новых показателей 
- Визуализация распределений и корреляционный анализ
- Выделение премиального сегмента и формулировка бизнес-рекомендаций

Стек: Python (Pandas, NumPy, Matplotlib, Seaborn), Jupyter Notebook
